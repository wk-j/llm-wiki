# Y Combinator

**Y Combinator (YC)** คือ startup accelerator และผู้จัด Startup School ใน wiki นี้เป็นผู้เผยแพร่ [[boris-cherny-cut-80-percent-claude-code-prompt|บทสัมภาษณ์ Boris Cherny]] ที่คุยเรื่อง Opus 5, การตัด system prompt ของ Claude Code, product overhang และ agent workflow ที่รันยาว

หน้าสรุปแยกคำพูดของ [[boris-cherny|Boris Cherny]] ออกจากหลักฐานที่ตรวจได้ภายนอก เพราะรูปแบบงานเป็นบทสัมภาษณ์เปิดตัว ไม่ใช่ technical report หรือ model card
