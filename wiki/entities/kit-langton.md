# Kit Langton

Kit Langton เป็นผู้เขียนเว็บไซต์ opencode notes ซึ่งรวบรวมบทความเกี่ยวกับ [[opencode|OpenCode]] หน้า index ของเว็บไซต์ระบุชื่อเขาเป็นผู้เขียน แต่บทความที่ ingest ครั้งนี้ไม่ได้ลงตำแหน่งงานหรือประวัติส่วนตัว จึงเก็บ entity นี้เท่าที่แหล่งยืนยันได้

ใน [[opencode-reloaded|OpenCode Reloaded]] เขาอธิบายสถาปัตยกรรม hot reload ของ OpenCode 2 แก่นคือให้ plugin ลงทะเบียน [[replayable-state-transformations|transformation ที่ replay ได้]] แล้ว rebuild registry จาก contribution ที่ยัง active แทนการให้ plugin หลายตัวแก้ shared state โดยตรง
