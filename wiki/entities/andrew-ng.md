# Andrew Ng / แอนดรูว์ อึ้ง

**Andrew Ng** (`@AndrewYNg` บน [[x-twitter|X]]) เป็นนักการศึกษาและผู้ประกอบการสาย AI ผู้ก่อตั้ง [[deeplearning-ai|DeepLearning.AI]] เขาเป็นหนึ่งในคนที่ทำให้ความรู้ machine learning กระจายออกนอกมหาวิทยาลัยได้กว้างที่สุดผ่านคอร์สออนไลน์

ใน wiki นี้เขาปรากฏครั้งแรกในฐานะผู้เสนอ [[ai-engineering-skills-map|AI Engineering Skills Map]]

## สิ่งที่เขาเสนอ (2026)

ใน [[andrew-ng-ai-engineering-skills-map|โพสต์บน X]] Ng ประกาศแผนที่ทักษะ AI engineering ที่ทีมเขาสังเคราะห์จาก job posting กว่า 10,000 ประกาศ, การสัมภาษณ์แบบมีโครงกับผู้เชี่ยวชาญ/hiring manager/recruiter, survey และข้อมูลออนไลน์อื่น ๆ

ทักษะสี่ข้อที่เขาสรุปได้:

1. Building and deploying AI applications — แกนคือ [[evals-and-error-analysis|eval กับ error analysis]]
2. Software engineering fundamentals — เพื่อให้มองเห็น tradeoff และสั่ง agent ได้ตรงคำ
3. Using coding agents — รู้ว่าเมื่อไหร่ควรแทรก เมื่อไหร่ควรปล่อย
4. [[shaping-the-build|Shaping the build]] — ตัดสินว่าอะไรควรอยู่ใน spec

จุดยืนเรื่องคำที่เขาย้ำคือ นี่เป็น "ทักษะ" ไม่ใช่ "ตำแหน่ง" — เขาเทียบกับ cloud ที่ developer ทุกคนต้องเป็น แต่คนที่มีตำแหน่ง Cloud engineer จริงมีน้อยกว่านั้นมาก

## จุดที่ควรอ่านอย่างระวัง

Ng เขียนในโพสต์เองว่า DeepLearning.AI มีเป้าหมายหลักคือช่วยให้ developer ได้ทักษะชุดนี้ ดังนั้นแผนที่จึงเป็นทั้งงานวิเคราะห์ตลาดและการวางตำแหน่งของสิ่งที่องค์กรเขาขายไปพร้อมกัน ตัวเลขที่อ้างยังไม่มีรายงานฉบับเต็มให้ตรวจ
