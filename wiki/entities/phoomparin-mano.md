# Phoomparin Mano

**Phoomparin Mano** คือนักสร้าง software และผู้ใช้ agent workflow ซึ่งเขียนโพสต์ Facebook เป็นภาษาไทย. ใน [[state-of-technology-and-joy-of-making-phoomparin-mano|State of Technology and the Joy of Making]] เขาเล่าความขัดแย้งระหว่าง AI ที่ช่วยให้คนทั่วไปสร้างของได้ กับ agent workflow ที่ทำให้คนทำงานเก่งขึ้นแต่รู้สึกห่างจากสิ่งที่ตัวเองสร้าง.

หน้านี้ระบุตัวตนจากชื่อและ stable profile permalink `phoomparin.mano` ที่แสดงบนโพสต์ Facebook เท่านั้น. ยังไม่ได้ตรวจประวัติการทำงาน องค์กร หรือบทบาทอื่นจาก source ภายนอก จึงไม่เติมรายละเอียดที่โพสต์ไม่ได้ให้.

## มุมมองที่บันทึกใน wiki

- AI ลดกำแพงการสร้าง software ได้จริง. คนแก้ปัญหาของตัวเองและแบ่งให้ community ใช้ได้โดยไม่ต้องรอ technologist ทุกเรื่อง.
- ความเร็วกับความหมายเป็นคนละ metric. Workflow อาจ optimal และ output ใช้งานได้ แต่คนทำยังเสีย [[creative-ownership|creative ownership]] ได้.
- ทางออกไม่ใช่กลัวเทคโนโลยี. ต้องถือด้านบวกกับด้านลบพร้อมกัน และรักษาพื้นที่ให้ creative coding, curiosity กับ mastery เติบโต.

**ได้อะไร:** Phoomparin เพิ่มเสียงของผู้ใช้ agent ที่เก่งและยังวิจารณ์ต้นทุนทางความหมายจากประสบการณ์ตรง ไม่ใช่คำวิจารณ์จากคนนอก workflow.
