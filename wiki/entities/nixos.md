# NixOS / Linux distribution ที่สร้างบน Nix

NixOS เป็น Linux distribution ที่ใช้ Nix จัด package และ configuration ใน wiki นี้ NixOS เข้ามาผ่าน [[cafkafk-nixos-omarchy-critique|โพสต์ของ cafkafk]] ซึ่งรายงานว่า [[dhh|DHH]] วางแผนให้ [[omarchy|Omarchy]] สร้างบน NixOS

โพสต์ไม่ได้อธิบายสถาปัตยกรรมหรือข้อแลกเปลี่ยนทางเทคนิคของ NixOS แต่เน้นว่าระบบนี้อยู่ได้จากงานหลายแบบ ทั้ง package, security, infrastructure, release engineering, review, maintenance และ governance ของชุมชน

## สถานะของ claim เรื่อง Omarchy

หน้า Omarchy เดิมบันทึกว่า distribution วางบน Arch ตามคำเล่าของ DHH ในบทสัมภาษณ์ ส่วน cafkafk รายงานแผนย้ายในภายหลัง สองข้อมูลนี้ไม่ได้หักล้างกันทันที เพราะอันหนึ่งบอกฐานในช่วงก่อน อีกอันบอกแผนที่ยังไม่ยืนยันว่าเสร็จแล้ว
