# Nixpkgs / ชุด package ของ Nix

Nixpkgs คือชุด package ที่ใช้ใน ecosystem ของ Nix และ [[nixos|NixOS]] [[cafkafk-nixos-omarchy-critique|โพสต์ของ cafkafk]] ยก Nixpkgs เป็นตัวอย่างของฐานที่ distribution ชั้นบนต้องพึ่ง ทั้งตัว package และงาน review, security, infrastructure กับ maintenance รอบมัน

แหล่งนี้ไม่ได้ลงรายละเอียดโครงสร้าง repository หรือกระบวนการออก release ประเด็นที่ใช้ใน wiki จึงแคบกว่านั้น คือ package collection ไม่ได้เกิดจากไฟล์ config อย่างเดียว แต่ต้องมี contributor ดูแลต่อเนื่อง
